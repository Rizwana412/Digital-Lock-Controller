## 🎥 Project Demonstration Video

A complete demonstration of the **Digital Lock Controller** project is provided in the project video.

The video explains the complete work carried out in this project, including:

- Introduction to the Digital Lock Controller
- Project objective and real-world application
- RTL design using Verilog/SystemVerilog
- Functional verification and testbench simulation
- RTL synthesis
- Static Timing Analysis (STA)
- Floorplanning
- Power planning
- Standard-cell placement
- Clock Tree Synthesis (CTS)
- Timing optimization and hold repair
- Global routing
- GDS/layout inspection using KLayout
- Challenges encountered during physical design
- Overall RTL-to-GDSII flow and project outcomes
